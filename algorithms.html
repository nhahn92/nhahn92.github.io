Algorithms and Data Structures

The artifact I selected for the Algorithms and Data Structures category is the enhanced trip listing functionality within the Travlr Getaways admin application. This work was originally created in CS‑465: Full Stack Development I, and it included basic trip display logic with minimal structure. For the capstone, I redesigned the search, sorting, and pagination features to make them more predictable, scalable, and efficient. I chose this artifact because it allowed me to demonstrate algorithmic thinking in a real application and show how thoughtful data handling improves both performance and user experience.

I included this artifact in my ePortfolio because it showcases how I evaluated existing logic, identified inefficiencies, and implemented improvements using algorithmic principles. The enhancement strengthened the artifact by replacing inconsistent or repetitive logic with clear, structured functions that handle searching, sorting, and pagination in a reliable way. These changes demonstrate my skills in problem‑solving, data manipulation, and designing predictable flows that scale as the dataset grows.

The process of enhancing this artifact taught me how important it is to think about performance and structure when working with data. One of the challenges I faced was understanding how the original application handled trip data, since some of the logic was scattered across multiple components and did not follow a consistent pattern. I had to reorganize the flow so that searching, sorting, and pagination worked together instead of competing with each other. This required careful planning and testing to ensure that each feature behaved correctly under different conditions.

Enhanced Search Algorithm (applySearch)
This function implements a structured linear search across multiple fields, including name, resort, and trip code, while normalizing input for consistent matching. The original logic was scattered across components, but reorganizing it into a single predictable function improved clarity, maintainability, and performance. This example demonstrates my competency in applying systematic filtering and ensuring search integrates cleanly with pagination.

Another challenge was making sure the logic remained efficient even as the dataset increased. I had to consider how many operations were being performed, how often the data was being filtered or sorted, and how to avoid unnecessary recalculations. This experience helped me better understand the trade‑offs involved in designing algorithms for real applications, especially when working with user‑driven features like search and filtering.

Pagination Algorithm (updatePagination)
This function computes page boundaries using Math.ceil() and array slicing to efficiently display only the relevant subset of trips. By centralizing pagination logic and ensuring it works in tandem with search, the enhanced version avoids redundant operations and scales cleanly as the dataset grows. This example demonstrates my competency in data structure manipulation and algorithmic efficiency within a real application.

Through this enhancement, I met course outcomes related to designing and evaluating computing solutions using algorithmic principles. I demonstrated my ability to analyze a problem, break it down into smaller parts, and implement a structured solution that improves performance and reliability. I also met outcomes related to software engineering by improving clarity, maintainability, and consistency within the codebase. I did not fully meet outcomes related to security in this enhancement, since those were addressed in other artifacts.
